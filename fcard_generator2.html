🔗 Cara Host

GitHub Pages: upload ke repo, namakan fail index.html (atau akses terus melalui nama failnya), kemudian Settings → Pages.
Netlify Drop: seret fail ke app.netlify.com/drop.
Google Sites: boleh dibenam (Embed → Embed code) tetapi ada had; GitHub Pages / Netlify lebih disyorkan.

Masukkan URL Google Apps Script, Kod Acara dan Kata Laluan Admin

Belum ada script? Klik butang di bawah untuk dapatkan kod

📋 Kod Google Apps Script

  1. Buka Google Sheets baharu di sheets.google.com (satu sheet ini untuk semua majlis)
  2. Klik Extensions → Apps Script, padam kod sedia ada
  3. Tampal kod di bawah dan tukar nilai ADMIN_KEY kepada kata laluan anda sendiri
  4. Klik Deploy → New deployment → Web app; Execute as: Me, Who has access: Anyone
  5. Salin URL /exec dan tampal dalam Builder (Langkah 2) serta Dashboard
Jika kod diedit kemudian: Deploy → Manage deployments → Edit → Version: New version → Deploy. Tanpa ini, URL lama masih menjalankan kod lama.
