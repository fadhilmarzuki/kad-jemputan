📋 Kod Google Apps Script

  1. Buka Google Sheets baharu di sheets.google.com
  2. Klik Extensions → Apps Script
  3. Padam semua kod sedia ada
  4. Tampal kod di bawah
  5. Klik Deploy → New deployment → Web app
  6. Execute as: Me | Who has access: Anyone
  7. Klik Deploy → Salin URL → Tampal dalam Builder
